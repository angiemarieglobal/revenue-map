# AMG Launch Revenue Map

The Angie Marie Global launch revenue calculator. Set monthly money goals, place offers and sales per month, and see contracts signed, cash received, future cash from payment plans, the sales needed to close each gap, and the funnel numbers behind them.

Live at https://angiemarieglobal.github.io/revenue-map/

Numbers typed into the page save in the browser that typed them. Use Save and share, Copy backup code to move a plan between devices.

Update flow: replace index.html, bump the version comment at the top of the file, commit. Pages redeploys in a few minutes.
